## CHUNKING STRATEGY RECOMMENDATIONS FOR RAG

### Recommended Chunking Levels

1. **H1 (Top-level chunks)**: Major sections of crop guides
   - Example: "Rice Cultivation → Climate Requirements"
   - Size: 1500-2500 tokens
   - Best for: Comprehensive questions requiring multiple related concepts

2. **H2 (Sub-sections)**: Detailed management topics
   - Example: "Climate → Temperature," "Soil → Characteristics"
   - Size: 800-1500 tokens
   - Best for: Specific farmer questions about particular topics

3. **H3 (Detail level)**: Specific practices or symptoms
   - Example: "Nutrient Deficiency Symptoms → Nitrogen"
   - Size: 300-800 tokens
   - Best for: Quick reference; specific answer to narrow question

### Chunking Rules

- **Preserve self-containment**: Each chunk explains terminology; doesn't rely on assumed context
- **Include context**: Reference broader topic when necessary
- **Avoid mid-sentence breaks**: Complete thoughts at chunk boundaries
- **Metadata inheritance**: Each chunk inherits document metadata

### Example Chunk Structure

```
Chunk ID: crop_rice_water_management_01
Document: crops/rice.md
Level: H2
Title: Water and Irrigation Management
Source: ICAR Rice Production Package
Applicable Regions: [India-wide]
Critical Stage: Yes (flowering, tuber bulking)

Content: [800-1200 words covering water requirement, critical stages, methods]
```

## RETRIEVAL STRATEGY RECOMMENDATIONS

### Multi-stage Retrieval

**Stage 1: Metadata Filtering**
- Filter by region (India-wide vs specific state)
- Filter by crop type
- Filter by category (soil, water, pests)
- Filter by season (Kharif, Rabi, year-round)

**Stage 2: Semantic Similarity**
- Query embedding: "How much water does rice need?"
- Similar vectors: Water requirement chunks, irrigation scheduling chunks
- Sort by relevance score

**Stage 3: Context Assembly**
- Primary chunk (most relevant)
- Supporting chunks (related topics)
- Cross-reference chunks (example from another crop for comparison)

### Query Type Examples

1. **Crop-specific management**: Filter crop → semantic search within crop docs
   - Example: "How to manage pests in cotton?" → Filter cotton → IPM section

2. **Soil-specific**: Filter soil type → semantic search within soil/fertilizer docs
   - Example: "Red soil cultivation" → Filter red soil → management practices

3. **Problem diagnosis**: Semantic search across all documents → filter by urgency
   - Example: "Yellow leaves on tomato" → Nutrient docs + disease docs + FAQ

4. **Comparative questions**: Multi-crop semantic search
   - Example: "Which crop needs more water: rice or cotton?" → Water requirement sections
